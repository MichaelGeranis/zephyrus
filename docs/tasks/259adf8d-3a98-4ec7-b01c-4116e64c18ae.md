## Task 2: Add deletion and preview API endpoints to existing controllers
**Agent:** BE

Add DELETE endpoints and preview endpoints to existing ProjectsController, FeaturesController, and ArtifactsController.

**API Contract Reference:**
- `DELETE /api/projects/{id}` → Returns `{deletedProjectsCount, deletedFeaturesCount, deletedArtifactsCount}`
- `DELETE /api/features/{id}` → Returns `{deletedFeaturesCount, deletedArtifactsCount}`
- `DELETE /api/artifacts/{id}` → Returns `{deletedArtifactsCount}`
- `GET /api/projects/{id}/deletion-preview` → Returns `{projectTitle, featuresCount, artifactsCount, warnings}`
- `GET /api/features/{id}/deletion-preview` → Returns `{featureTitle, artifactsCount, warnings}`

**Files to modify:**
- `Api/Controllers/ProjectsController.cs` - Add DeleteProject and GetDeletionPreview actions
- `Api/Controllers/FeaturesController.cs` - Add DeleteFeature and GetDeletionPreview actions
- `Api/Controllers/ArtifactsController.cs` - Add DeleteArtifact action
- `Api/DTOs/DeletionSummaryDto.cs` - New DTO for deletion response
- `Api/DTOs/DeletionPreviewDto.cs` - New DTO for preview response

**Acceptance Criteria:**
- [ ] DELETE endpoints return 200 OK with deletion summary on success
- [ ] DELETE endpoints return 404 Not Found for non-existent entities
- [ ] Preview endpoints return 200 OK with count data
- [ ] Preview endpoints return 404 Not Found for non-existent entities
- [ ] All endpoints include proper error handling with 500 status codes
- [ ] Response DTOs match the specified API contracts exactly
- [ ] Controllers properly inject and call the corresponding use cases
